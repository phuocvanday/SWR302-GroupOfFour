# UC-17 — Approve PT Account

> Issue: #23 · Branch: `step4/huy-uc-16-17`

| Field | Content |
|-------|---------|
| **UC ID and Name** | UC-17 — Approve PT Account |
| **Created By** | huyd06@example.com |
| **Date Created** | 10/11/2026 |
| **Primary Actor** | Gym Owner |
| **Secondary Actors** | SMS Service |
| **Trigger** | The Gym Owner receives a notification of a new PT registration or opens the "PT Management -> Pending List" page. |
| **Description** | The Gym Owner reviews the PT's detailed profile, credentials, and certificate while the account is in `PENDING` status and decides whether to approve or reject the application with a reason. |
| **Preconditions** | 1. The Gym Owner has successfully logged in to the system with administrator privileges.<br>2. At least one PT account is in `PENDING_APPROVAL` status. |
| **Post conditions** | **Approval case:**<br>1. The PT account status changes to `ACTIVE`.<br>2. The system allows the PT to log in and set up PT training packages.<br>3. A success SMS notification is sent to the PT's phone number.<br><br>**Rejection case:**<br>1. The PT account status changes to `REJECTED`.<br>2. The rejection reason is stored, and an SMS notification including the reason is sent to the PT. |
| **Normal Flow** | 1. The Gym Owner accesses the "PT Management" menu and selects the "Pending Profiles" tab.<br>2. The system displays the list of PTs awaiting approval (full name, registration date, specialization).<br>3. The Gym Owner selects a PT profile to view details.<br>4. The system displays the full profile: personal information, years of experience, description, and a preview of the certificate file.<br>5. The Gym Owner checks the certificate and clicks the "Approve" button.<br>6. The system displays an approval confirmation dialog.<br>7. The Gym Owner selects "Confirm".<br>8. The system updates the PT account status to `ACTIVE`.<br>9. The system automatically sends a congratulatory SMS and login instructions to the PT via the SMS Service.<br>10. The system displays the message "The PT account was approved successfully". |
| **Alternative Flows** | **5a. The Gym Owner rejects the profile:**<br>1. At step 5, the Gym Owner clicks the "Reject" button.<br>2. The system displays a pop-up requiring a rejection reason (required, e.g. "Certificate is invalid", "Insufficient experience").<br>3. The Gym Owner enters the reason and clicks "Confirm rejection".<br>4. The system updates the PT account status to `REJECTED` and saves the reason.<br>5. The system sends an SMS notification to the PT with the rejection result and reason.<br>6. The system displays "The PT profile was rejected". |
| **Exceptions** | **4a. Certificate file cannot be loaded:**<br>1. The system cannot display the certificate file because the stored file is corrupted.<br>2. The system shows "Unable to load certificate file" and allows the Gym Owner to request that the PT resend it via email or phone number.<br><br>**8a. Database update error:**<br>1. The database connection is interrupted while changing the status.<br>2. The system shows "Unable to update status. Please try again" and keeps the current status as `PENDING`. |
| **Priority** | High |
| **Frequency of Use** | Frequent (Several times per week depending on the number of new PT registrations). |
| **Business Rules** | BR-03 (A PT account is only active after approval by the Gym Owner).<br>BO-04 (PT registration files must be processed within 24 hours). |
| **Other Information** | **UI Screen:** `03_Images/UI_UC-17_ApprovePT.png`<br>**AD Reference:** AD-02 (Swimlane Activity Diagram: Register & approve PT). |
| **Assumptions** | The Gym Owner has sufficient expertise to verify the authenticity of the trainer certificates uploaded by applicants. |
