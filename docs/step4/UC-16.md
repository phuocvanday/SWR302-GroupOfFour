# UC-16 — Register PT Account

> Issue: #23 · Branch: `step4/huy-uc-16-17`

| Field | Content |
|-------|---------|
| **UC ID and Name** | UC-16 — Register PT Account |
| **Created By** | huyd06@example.com |
| **Date Created** | 10/11/2026 |
| **Primary Actor** | Personal Trainer (PT) |
| **Secondary Actors** | SMS Service |
| **Trigger** | The user (PT) accesses the website or application and clicks the "Register as PT" button. |
| **Description** | The PT enters personal information, area of expertise, experience, and uploads professional certificates to register a PT account in the system. The profile remains in pending status (`PENDING`) until the Gym Owner reviews it. |
| **Preconditions** | 1. The system is operating normally.<br>2. The PT's phone number and email have not been registered in the system before. |
| **Post conditions** | 1. The PT account is successfully created with `PENDING` status.<br>2. The PT's certificate information and professional profile are securely stored in the database.<br>3. The system sends a confirmation notification to the PT and a review alert to the Gym Owner. |
| **Normal Flow** | 1. The PT selects "Register as PT" on the login screen.<br>2. The system displays a registration form with fields for full name, phone number, email, password, specialization (Gym/Yoga/Boxing), years of experience, self-description, and certificate upload (PDF/PNG/JPG).<br>3. The PT fills in all required information and uploads the certificate file.<br>4. The PT clicks the "Register" button.<br>5. The system validates the data format (valid email, valid phone number, certificate size ≤ 5MB).<br>6. The system checks the uniqueness of the email and phone number in the database.<br>7. The system saves the PT account with `PENDING_APPROVAL` status.<br>8. The system sends an OTP verification code via the SMS Service to the registered phone number.<br>9. The PT enters the correct OTP and clicks "Verify".<br>10. The system displays the message "Registration successful! Your profile is pending Gym Owner approval within 24 hours". |
| **Alternative Flows** | **4a. Phone number or email already exists:**<br>1. At step 6, the system detects that the email or phone number is already in use.<br>2. The system displays an error message: "Email or phone number has already been registered".<br>3. The system keeps the entered information and asks the PT to change the phone number or email, or redirects them to Login.<br><br>**9a. Incorrect OTP entered:**<br>1. At step 9, the PT enters the wrong OTP.<br>2. The system displays the error "OTP is incorrect. N attempts remaining".<br>3. The PT can re-enter the code or choose "Resend OTP". |
| **Exceptions** | **3a. Invalid certificate file or oversized file (CON-1):**<br>1. The PT uploads a `.exe` file or a file larger than 5MB.<br>2. The system blocks the upload and displays the error "File is invalid or exceeds the 5MB limit".<br><br>**8a. SMS gateway connection error:**<br>1. The system fails to send the OTP via the SMS Service.<br>2. The system displays "The SMS service is temporarily unavailable. Please try again later" and returns to step 4. |
| **Priority** | High |
| **Frequency of Use** | Low (Approximately a few times per week when new PTs apply). |
| **Business Rules** | BR-03 (Each PT account must be approved by the Gym Owner after certificate verification).<br>CON-1 (Compliance with Decree 13/2023/NĐ-CP on personal data protection). |
| **Other Information** | **UI Screen:** `03_Images/UI_UC-16_RegisterPT.png`<br>**AD Reference:** AD-02 (Register & approve PT). |
| **Assumptions** | It is assumed that the PT candidate has already prepared digital scans or files of their professional certifications. |
